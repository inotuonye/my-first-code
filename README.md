# Python Starter Projects

A collection of beginner-friendly Python programs demonstrating core programming concepts.

## 🧠 Projects Included

1. **Celsius-Fahrenheit Converter**
   - Converts between Celsius and Fahrenheit.
   - Includes simple user input and formatted output.

2. **Grading Script**
   - Takes numerical grades and outputs letter grades.
   - Introduces conditionals and input validation.

## ⚙️ How to Run
```bash
python3 celsius-fahrenheit-tool.py
python3 grading.script.py
